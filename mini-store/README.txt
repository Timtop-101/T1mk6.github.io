Mini Store — игровое веб-приложение для iPhone и iPad.

Как запустить:
1. Загрузите ВСЕ файлы папки на HTTPS-хостинг, например GitHub Pages.
2. Откройте адрес в Safari на iPhone/iPad.
3. Меню «Поделиться» → «На экран Домой» для значка приложения.
4. Откройте «Обучение» и добавьте фото каждой коробки. Затем сканируйте в «Сканер».

Важно: распознавание — приблизительное локальное сравнение с добавленными снимками, не искусственный интеллект. Для похожих коробок лучше использовать разные фоны или ручной выбор из каталога. Фото не отправляются на сервер; сохраняются числовые признаки в localStorage на конкретном устройстве. Список товаров и цены встроены в app.js.
