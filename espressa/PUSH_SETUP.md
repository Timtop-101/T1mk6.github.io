# Push-уведомления EspressA

Код сайта и Firebase Cloud Functions подготовлен. **Уведомления не заработают автоматически, пока не выполнены действия ниже.**

1. Firebase Console → Project settings → Cloud Messaging → Web Push certificates → Generate key pair. Скопировать **только публичный VAPID key** и вставить в `window.ESPRESSA_FCM_VAPID_KEY` файла `espressa/push-config.js`. Никогда не публиковать приватный ключ.
2. GitHub Actions → Deploy EspressA Firestore Rules: убедиться, что новые правила `espressa/firestore.rules` опубликованы (правила подписок `pushSubscriptions`).
3. Для автоматической отправки уведомлений Firebase Cloud Functions (2nd gen) требует настройки биллинга/Blaze и разрешений для деплоя; существующий GitHub Actions публикует **только правила** и функции не разворачивает. После включения соответствующих разрешений и биллинга выполнить из каталога `espressa`: `npm --prefix functions install` затем `npx firebase-tools deploy --only functions --project espressa-80660`. Выполняйте в доверенной среде, авторизованной вашим аккаунтом Google. Деплой может потребовать дополнительных IAM-ролей и сервисных API.
4. Войдите в кабинет клиента или сотрудника и нажмите «🔔 Уведомления». Разрешите их в браузере. На iOS/iPadOS (16.4+) необходимо добавить сайт на домашний экран и открывать именно установленную веб-версию.
5. С клиента с аккаунтом оформите заказ: сотрудникам приходит уведомление. При смене статуса сотрудником клиенту приходит уведомление. Для заказа гостя push клиенту не отправляется.

Не добавлять ключи Admin SDK в GitHub; Cloud Functions получает права сервисного аккаунта автоматически. Для безопасного тестирования проверьте фактическую публикацию и стоимость Cloud Functions.
